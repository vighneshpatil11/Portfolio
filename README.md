# Vighnesh Patil — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Before publishing — please review
1. Confirm that the listed skills reflect your current level.
2. Review the project descriptions and technology tags, especially MeshSOS and Robotic Arm, and adjust them if their current README details differ.
3. Add links to live demos / repositories where available.
4. The document security project currently links to your IIDTL GitHub repository. Confirm that this is the correct public project link.
5. Add a resume link if you want one.
6. Your email and LinkedIn are included. A phone number is intentionally not displayed publicly.

## Publish free
- GitHub Pages: create a repository, upload these files, then enable Pages in repository Settings.
- Netlify: drag the extracted folder into Netlify Drop.
- Vercel: import the GitHub repository as a static site.

The design uses Google Fonts from a CDN; it falls back to system fonts if unavailable.
